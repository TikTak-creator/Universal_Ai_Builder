# Visual Toolkit v0.2

Обновление расширяет существующий редактор. Сохраняются текущие проекты, вложенность, геометрия, история и локальная работа.

## Иконки

Откройте **Элементы → Иконка**. Каталог содержит 120 иконок Lucide: Интерфейс, Общение, Бизнес, Творчество, Технологии, Мир вокруг. Поиск работает по русским подписям и английским названиям. Перед вставкой можно выбрать цвет, толщину и мягкий фон. Перетаскивание компонента «Иконка» сразу добавляет Sparkles, которую затем можно заменить в инспекторе.

После вставки иконка является отдельным векторным компонентом: перемещается, масштабируется и поворачивается средствами редактора. В инспекторе можно заменить символ, поменять цвет/толщину и отразить по двум осям. Мягкий фон — обычная заливка, отступ и радиус; все эти значения доступны для дальнейшей настройки.

## Независимые углы

В панели **Углы** четыре поля соответствуют углам компонента. Когда цепочка включена, любое поле меняет общий радиус. Нажмите **Развязать углы**, чтобы настраивать их независимо.

Маркеры вокруг образца можно тянуть внутрь для увеличения радиуса и наружу для уменьшения. Движение одного маркера не меняет остальные независимые углы. Escape отменяет жест, Undo отменяет весь жест одним шагом. Числовые значения сохраняются в px. Если радиусы больше допустимых для размеров элемента, браузер визуально нормализует их по правилам CSS.

Углы работают для фонов, рамок и загруженных изображений. Обрезка вложенных элементов задаётся отдельно через **Контейнер → Переполнение → Обрезать**.

## Шрифты

Нажмите **Aa** сверху или **Типографика → Шрифты**. Перетащите TTF/OTF/WOFF/WOFF2 в загрузчик либо выберите файл. Файл проверяется по сигнатуре и декодируется через FontFace до добавления. Один шрифт не больше 4 МБ; суммарно до 16 МБ и 30 файлов.

Manrope включён в `public/fonts` вместе с OFL-лицензией и доступен кнопкой **Установить** без интернета. Он содержит кириллицу и поддерживает веса 200–800. Загруженный шрифт автоматически применяется к выбранным текстовым элементам. Его также можно выбрать в обычном списке «Шрифт» или применить к нескольким выбранным текстовым элементам из менеджера.

Вес и стиль в менеджере описывают сам файл: для отдельного Bold-файла задайте 700; для вариативного файла — соответствующий диапазон. Курсив для отдельного italic-файла также задаётся здесь. Кнопки курсива и веса в инспекторе управляют оформлением конкретного элемента.

Повторная загрузка одинаковых байтов использует существующий ресурс. Имя для отображения можно изменить. При удалении шрифта элементы переходят на системный шрифт; Undo восстанавливает ресурс и оформление.

Данные шрифта включаются в JSON, автосохранение и clipboard редактора. При вставке текста в другой проект шрифт переносится; конфликтующие ID/семейства переименовываются без подмены уже используемых шрифтов. Для Manrope в JSON включается и его лицензия. Системные шрифты доступны через CSS и не копируются с компьютера в документ.

## Другие настройки

- Заливка: сплошной цвет или linear/radial/conic-градиент, два цвета, угол, пять пресетов.
- Эффекты: до восьми теней, каждая с X/Y, blur, spread, цветом, непрозрачностью и inset. Пресеты мягкой тени, свечения и внутренней тени.
- Blur и backdrop blur — отдельно, от 0 до 100 px. Для видимого backdrop blur обычно нужна частично прозрачная заливка.
- Наложение: normal, multiply, screen, overlay, darken, lighten.
- Типографика: шрифт, размер, вес, межстрочный и межбуквенный интервалы, выравнивание, курсив, подчёркивание, зачёркивание и регистр.
- Рамка: цвет, толщина, solid/dashed/dotted. Рамка не сдвигает начало координат вложенных элементов.
- Изображения: cover, contain, fill, scale-down.

Холст и предпросмотр используют одни и те же стили. Настройки сохраняются в модели v2. Миграция v1 дополняет старые документы безопасными значениями по умолчанию и сохраняет исходный общий радиус.

## Лицензии и границы

Иконки Lucide распространяются по ISC; часть унаследованных Feather-иконок — по MIT. Уведомление пакета включено в `public/licenses/lucide.txt`. [Официальная лицензия Lucide](https://lucide.dev/license).

Manrope распространяется по SIL Open Font License 1.1. Файл лицензии находится рядом со шрифтом. Источник: [Google Fonts — Manrope](https://github.com/google/fonts/tree/main/ofl/manrope).

Это дополнение к Free Design, а не завершение всей Phase 2. Flex/Grid, breakpoints, токены, события, анимации и генераторы HTML/React/Flutter пока не реализованы. Новых внешних API, платных сервисов и AI-запросов нет.
