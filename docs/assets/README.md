# Documentation artwork

`forma-jjk-banner.png` is the exact banner supplied by the repository owner for the README. It is decorative Jujutsu Kaisen fan art, not a screenshot and not a statement of implemented features. The characters belong to their respective rights holders. No official affiliation is claimed, and no broad redistribution license for the artwork is asserted.

The decorative banner is used in documentation/source only; it is not loaded into the editor, bundled as a built-in template, or included in the Windows runtime. Actual editor screenshots are the existing `docs/editor-desktop.jpg`, `docs/icon-library.jpg`, and `docs/font-manager.jpg`.

`desktop/icon.png` and `.ico` are a simple code-drawn F mark based on the existing Forma favicon. Runtime notices for Lucide, Feather and Manrope remain under `public/`.
